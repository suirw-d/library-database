# Library Database

A database project for managing a library's books.

## Description

This project is designed to provide a simple database system for managing the main operations of a library, along with providing a simulation of said library.

Current features include:
- Adding books
- Removing books
- Editing books
- Searching through the database
- Simulation of a library (clients coming over, picking out books to their liking and employees restocking and servicing clients)
